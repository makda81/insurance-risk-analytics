# Insurance Risk Analytics

## Project Overview

This project analyzes vehicle insurance data for AlphaCare Insurance Solutions.

The goal is to understand risk patterns, build predictive models,
and support risk-based pricing decisions.

## Objectives

- Perform Exploratory Data Analysis
- Analyze insurance claims
- Conduct hypothesis testing
- Build machine learning models
- Explain model predictions

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Git
- DVC
